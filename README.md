# NovaMart

React + Vite storefront. Har component ki apni `.jsx` aur `.css` file hai (vanilla CSS).

## Run
```
npm install
npm run dev
```

## Structure
- `src/index.css` — global variables, reset, shared utilities
- `src/components/` — Header, CartDrawer, ProductCard, Hero, TopBrands, DealOfTheDay, Categories, FlashSale, JustForYou, Journal, StoreFeatures, Testimonials, Newsletter, Footer
- `src/pages/` — HomePage, ProductDetail, AuthPage
- `src/data/products.js` — product list
